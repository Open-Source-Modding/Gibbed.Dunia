# Far Cry 3 (+ Blood Dragon) file lists (Gibbed.Dunia)

Seeded from the FCCU (Far Cry Custom Units) 2017 filelist snapshot
(from DuniaTools projects). These are UNVERIFIED against a real install —
run `RebuildFileLists` against the actual game to validate and extend:

    dotnet run --project Gibbed.FarCry3.RebuildFileLists -- <game>/<data dir>/

- 323283 unique names
- See https://github.com/Open-Source-Modding/Gibbed.Dunia for the tools
